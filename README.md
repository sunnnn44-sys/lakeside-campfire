# 호숫가 모닥불

밤 호숫가 모닥불에 동물이 되어 둘러앉는 3D 웹페이지입니다. three.js로 그리고, 서버 없이 브라우저끼리 바로 연결(Trystero)해서 여러 명이 함께 앉습니다.

- 한 모닥불에 12명까지, 넘치면 옆 모닥불로 갑니다.
- 할 수 있는 것: 손 흔들기, 불 쬐기, 종이배 띄우기. 자유 채팅은 없습니다.
- 종이배에 적은 걱정은 내 화면에만 보이고, 다른 사람에게는 불 켜진 배만 갑니다.
- '친구 부르기'를 누르면 주소를 받은 사람끼리만 앉는 친구 모닥불이 만들어집니다.

## 파일

- `lakeside-campfire.html` — 원본 페이지
- `assets/` — 모델·텍스처
- `build-site.ps1` — 원본을 완성된 HTML로 감싸 `docs/`에 만듭니다. 원본을 고친 뒤 다시 실행하세요.
- `docs/` — GitHub Pages로 공개되는 폴더
